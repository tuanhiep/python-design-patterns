# Python Design Patterns

Python examples for classic object-oriented design patterns and SOLID principles.

## Purpose

This repository is a learning reference for understanding design patterns through small Python examples.

## Contents

- SOLID principle examples.
- Creational, structural, and behavioral pattern examples.
- Folder-per-pattern organization for quick review.

## How To Use

Open a pattern folder and run the example Python files directly.

```bash
python path/to/example.py
```

## Status

Active reference repo. The next upgrade is to add one-page notes per pattern covering intent, trade-offs, and when not to use it.

## Validation

Each pattern example should run independently and show the behavior that changes when the pattern is applied.

## Engineering Notes

The value is not memorizing pattern names; it is making intent, trade-offs, and misuse cases explicit.
